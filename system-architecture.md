# Savora AI System Architecture

## Overview
Savora will be an AI-powered bakery business system that handles customers, marketing, and sales automatically.

---

## Modules

### 1. Customer Interface
- Website (Next.js)
- Product browsing
- Order placement
- Chat assistant

### 2. AI Assistant
- Answers questions
- Recommends products
- Handles objections
- Guides purchase

### 3. Automation Layer (n8n)
- Order notifications
- Customer follow-ups
- Marketing automation
- Lead capture

### 4. Database Layer (Supabase)
- Users
- Orders
- Messages
- Analytics

### 5. Admin System
- View orders
- Manage products
- Track performance

---

## Flow

User → Website → AI Assistant → Database → Automation → Team notification
